Panduan Cara Install Sebagai Aplikasi Native

Agar Opalis AI muncul di Layar Utama HP / Laptop Anda sebagai aplikasi mandiri (standalone app) tanpa address bar browser, ikuti langkah mudah berikut:

📱 Di Android / Chrome Mobile:

  1. Klik ikon Titik Tiga (⋮) di pojok kanan atas browser Chrome HP.
  2. Pilih menu "Tambahkan ke Layar Utama" (Add to Home screen) atau "Install Aplikasi".
  3. Klik Install. Aplikasi akan langsung muncul di menu HP dengan ikon tersendiri!

💻 Di Komputer / PC (Chrome, Edge, Brave):

  1. Lihat di Address Bar (bilah alamat URL) sebelah kanan atas.
  2. Klik ikon Install (↓) atau klik tombol "Install App" di bawah.
  3. Aplikasi akan berjalan dalam jendela tersendiri layaknya software bawaan Windows!
